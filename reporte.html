Qué les interesa

Lista (los más recientes primero)

Datos personales. La lista de personas que ingresaron tiene nombres y emails: usarla solo para lo que dice la política de privacidad (saber quién visita la web y qué le interesa), no compartirla y no usarla para mandar publicidad. Si alguien pide ver o borrar sus datos, se hace desde el SQL Editor de Supabase (ver temporada.sql, parte 6).

Cómo se mide. La app registra eventos sin cookies ni IP ni ubicación. Son anónimos, salvo los de quienes ingresaron con nombre y email. Las inscripciones se cuentan cuando la base confirma el lugar; si después alguien cancela, sigue contando acá. Para medir carteles, el código QR de cada uno lleva su propio origen (por ejemplo ?src=qr-costanera). Los días y horarios son de Posadas.
